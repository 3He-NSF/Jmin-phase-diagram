# Jmin phase diagram

Python code for calculating and visualizing the minimum-energy wave vector \( q_{\min} \) in the \( J_1-J_2-J_3 \) model.

## Features

- Direct minimization of \( J(\mathbf{q}) \)
- Visualization of:
  - \( q_{\min} \) as RGB color map
  - \( J(q_{\min}) \) energy map
- Adjustable scan ranges for:
  - \( J_2/J_1 \)
  - \( J_3/J_1 \)
  - reciprocal-space coordinates

## Requirements

- Python 3
- numpy
- matplotlib
